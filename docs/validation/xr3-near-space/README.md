# Private integration validation receipts

These exact JSON receipts were generated by the frozen near-space integration candidate under Unity 6000.3.27f1 on the Mac Editor. The final focused run passed 71 cases. They are baseline measurements to reproduce when validating a future standard/full source port, not results from that port.

- `actual-module-bounds-24roots.json`: actual WorldSpace consumer,24 registered roots/24 dynamic Graphics, original 2-corner/correct 4-corner/batched 4-corner comparison.
- `paired-dynamic-geometry-cost-24roots.json`: separate four-call generic geometry bundle,24 registered roots including nested ownership, dynamic aircraft/UI, diagnostics disabled during timings; parity within noise.
- `enabled-camera-gpu.json`: 80 normal enabled-camera frames with projection/inverse-click/actual raster/AABB equivalence.

No Windows FPS, crash resolution, sustained-flight or wearer acceptance is inferred from these receipts. The initial one-root benchmark and regressed intermediate24-root candidate are not used as final performance claims.
